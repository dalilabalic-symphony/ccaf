DOMAIN 1 27% of exam

Agentic Architecture & Orchestration

The single biggest domain — agent loops, coordinator/subagent patterns, hooks, task decomposition, and session management.

DAY 1 Sat, Aug 8
✓

Agentic loop fundamentals

Prerequisite skim (optional, 10–15 min)

If the Claude API is new to you: Ch. 1.1–1.2, 1.4 (Request Structure, Message Roles, System Prompt) and Ch. 2.1 (What is tool_use) — not tied to a specific task statement, but everything downstream assumes you know this shape.

Study — Task 1.1

stop_reason handling ("tool_use" vs "end_turn"), tool result → context loop, model-driven vs pre-configured decision-making.

Guide references

Ch. 1.3 (the stop_reason field), Ch. 3.1 (What is an Agentic Loop), Part II Domain 1 §1.1.

Do

Build a minimal agentic loop with the Agent SDK; verify it terminates correctly on "end_turn" and continues on "tool_use". Avoid anti-patterns: don't parse NL text for termination, don't use arbitrary iteration caps as primary stop logic.

DAY 2 Sun, Aug 9
✓

Coordinator/subagent orchestration & context passing

Study — Tasks 1.2–1.3

Hub-and-spoke orchestration, isolated subagent context, dynamic subagent selection, iterative refinement loops. Task tool + allowedTools, explicit context passing (subagents don't auto-inherit), AgentDefinition, fork_session.

Guide references

Ch. 3.2 (AgentDefinition Configuration), Ch. 3.3 (Hub-and-Spoke: Coordinator and Subagents), Ch. 3.4 (The Task Tool for Spawning Subagents), Part II Domain 1 §1.2–1.3.

Do

Sketch a coordinator that decides which subagents to invoke based on query complexity, not a fixed pipeline. Then spawn 2 parallel subagents via multiple Task calls in one response, passing prior findings explicitly with structured metadata (source URL, doc name).

Do

EXAM DAY Fri, Aug 28, 2026

Sit the exam

Arrive/log in early. Remember: 4 scenarios drawn from a bank of 6 (Customer Support Agent, Code Generation, Multi-Agent Research, Developer Productivity, CI/CD, Structured Data Extraction) — each maps to specific domains, so use the scenario framing to recall which task statements apply.

Out of scope — don't over-study this

Explicitly excluded from the official exam guide.

  • Fine-tuning / training custom models
  • Claude API authentication, billing, or account management
  • Deep framework-specific coding beyond tool/schema configuration
  • Deploying or hosting MCP servers (infrastructure, networking, container orchestration)
  • Claude's internal architecture, training process, or model weights
  • Constitutional AI, RLHF, or safety training methodologies
  • Embedding models or vector database implementation details
  • Computer use (browser automation, desktop interaction) or Vision/image analysis
  • Streaming API / server-sent events
  • Rate limiting, quotas, detailed API cost calculations
  • OAuth, API key rotation, authentication protocol details
  • Cloud-provider-specific configurations (AWS, GCP, Azure)
  • Performance benchmarks or model comparison metrics
  • Prompt-caching implementation details (beyond knowing it exists)
  • Token counting algorithms or tokenization specifics
